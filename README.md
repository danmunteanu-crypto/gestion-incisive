# Gestion Incisive

A bilingual, responsive marketing website for Gestion Incisive, focused on incoming dental-practice calls, insurance estimates and follow-ups, and outbound recalls. The site presents the company’s human-first positioning: experienced staff empowered by AI.

## Run locally

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Built with React, TypeScript, Vite and Tailwind CSS. Brand imagery and clinic logos are stored in `public/images/`.
